# aftersig

Paste a Solana transaction signature. Optionally write what you (or your agent) meant to do.

Get back: what actually landed vs that intent, human-readable errors (incl. Anchor codes), SOL/token balance deltas, and a JSON blob agents can ingest.

Daily-use tool. Not a metaphor. Not a dossier.
